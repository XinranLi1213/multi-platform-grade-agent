# 可上传体验案例

全部为合成数据，不是真实学生。每次只上传一个案例中的全部CSV，复制其“任务提示词.txt”。

建议按下列顺序试用；先用01验证无模型也可工作，再配置模型体验其余场景。异常案例应暂停，不是程序失败；模型/API失败需重试或手动修正，不算业务成功。

2. [02_完整40人](02_完整40人)：任务、CSV、预期及必要补充答案均在同目录。
3. [03_同名身份歧义](03_同名身份歧义)：任务、CSV、预期及必要补充答案均在同目录。
4. [04_提交时间缺失](04_提交时间缺失)：任务、CSV、预期及必要补充答案均在同目录。
5. [05_自定义展示项目](05_自定义展示项目)：任务、CSV、预期及必要补充答案均在同目录。
6. [06_未知满分与自定义回答](06_未知满分与自定义回答)：任务、CSV、预期及必要补充答案均在同目录。
