双阶段执行：运行前验收预期

测试输入由独立 tests/generate_two_stage.py 生成，正式入口不调用生成器。参考答案也由独立Python Decimal程序计算后保存，禁止用模型心算充当数值参考。

| 编号 | 条件 | 预期 |
| --- | --- | --- |
| 01 | 花名册、实验平台、作业平台；完整权重及未交政策 | 自动识别说明/表头/汇总；实验max、作业latest；无异常自动DWD→DWS，结果等于Python参考答案 |
| 02 | 文件行序与时间顺序相反 | latest使用提交时间，不使用末行；时间缺失时暂停而非猜测 |
| 03 | 无编号同名但有唯一班级；另测同名无辅助信息 | 前者自动补齐并审计；后者暂停，教师给出编号和依据后基于原上传续算 |
| 04 | 去重缺时间、相同时间冲突或明确教师裁决 | 不任意选记录；明确裁决及其原记录保留审计 |
| 05 | 优/良/不及格/缓考 | 仅按明确默认等级表折算；缓考在DWD原样保留，DWS按明确规则继续保留 |
| 06 | 未交没有阶段二政策 | DWD可以ready，DWS暂停；补未交记0后仅重算DWS，DWD哈希及原状态不变 |
| 07 | 重复考勤记录未说明sum/mean | 暂停选择策略；明确sum后实际Python汇总和折算，不猜均值或累加 |
| 08 | 非主表编号 | Left Join主表之外记录进入异常与逐条账本，未经确认阻断；明确排除或追加主表后继续，不静默丢失 |
| 09 | 受限表达式描述N选M、封顶、条件绩点 | 生成并执行独立Python，结果与独立参考程序一致 |
| 10 | 新完整权重试算 | DWD全部文件与哈希不变，另存新Python/规则/输出；比较前后逐人差异与同口径优秀率 |
| 11 | “实验权重提高10%”或权重合计不为100% | 询问百分点/相对比例、其余权重和优秀率口径；不自行归一 |
| 12 | 任意Python、属性、导入、文件读取、公式字段不存在 | 结构检查拒绝，不执行任意模型代码 |
| 13 | DWD被改动或仍blocked | 阶段二拒绝接收；原始上传不能直接充当阶段二输入 |
| 14 | 坏行、空文件、不明确分制 | 明确暂停与影响位置，原始输入保留，不能部分读取后宣称100%干净 |
| 15 | 重启、旧revision、未配置真实LLM | 持久会话可恢复，旧版本拒绝；明确语义功能未启用，不用模拟回复替代 |
| 16 | 跨平台同一项目数值冲突 | 草稿标为冲突且保留双方来源，明确裁决后继续，不能自动取某侧 |
| 17 | 无法理解的追加指令；只说“换算成百分制”但没有原满分 | 不冒充已执行变更，不用旧公式替代；不推断原始分制 |
| 18 | 阶段二CSV或公式文件被修改 | 拒绝不一致下载；生成代码绑定业务规则哈希，不能改政策后冒充原执行 |
| 浏览器 | 正常自动流程、确认卡、身份补充、试算与导出 | 页面所见与API持久数据一致；两阶段下载CSV与各自预览逐字段一致 |
