# 教师项目控制台

安装包含Tcl/Tk的Python 3.11及以上，将项目放在普通可写目录。双击项目根目录的 **启动控制台.vbs**，只显示图形界面；若Windows禁用脚本宿主，可双击 **启动控制台.cmd**。原 **start.cmd** 仍是命令行启动入口，两者不要同时使用同一端口或同一状态目录。

正常操作：选择或输入密钥（也可手动模式）→启动服务→健康检查通过→打开教师页面→上传并完成任务→关闭项目页面→停止服务→退出。运行中的接口修改须停止后重启，不会偷偷更新现有进程。控制台默认状态目录为runtime/state；如选择旧state，请确认没有另一个服务使用它，原始文件不会迁移或清空。

模型配置继续使用config/model_config.local.json。现有DeepSeek地址、模型及其他合法选项会保留；支持共享的非流式Chat Completions协议。界面中未显示的合法选项（如样例发送、超时、环境变量名）不会因保存表单而被删除。修改地址/模型可用于本次启动，点击保存后才供下次使用。

密钥来源以界面明确选择为准：新输入会切换到“本次输入”；初次默认环境变量→本机已保存→手动。不回填已有密钥，不显示密钥片段。即使存在环境变量，选择手动也不会在子服务中偷偷使用它。

- 默认不勾选记住；临时密钥只保留在控制台内存及所启动子服务的环境中，不写文件、不进命令行参数。
- 勾选“在本机记住密钥（明文）”并点击保存或启动，才写config/secrets.local.json。该文件是**明文，未加密**，只适用于可信的个人电脑。
- 更新：输入新密钥、勾选记住、保存；清除：点击“清除本机已存密钥”。清除不修改外部环境变量或已启动服务的内存，所以需要重启。
- 如果密钥文件已经被Git跟踪，拒绝写入或使用，并明确提醒处理；不会自动操作Git索引或历史。正式包和开发源码包均排除该文件。
- 可以手动创建文件，格式如下（下面只是占位示例，不能直接作为真实密钥）：

```json
{
  "version": 1,
  "keys": {"INTEGRATION_MODEL_API_KEY": "REPLACE_WITH_YOUR_REAL_KEY"}
}
```

keys的名称对应普通配置中的api_key_env。保留命令行环境变量方式，原start.cmd使用环境变量优先、本机文件回退，并显示来源。网页不接收密钥，浏览器存储不保存密钥。

“检查模型连接”会从独立服务端进程实际调用当前接口，发送固定连接检查JSON，不发送教师文件。检查不自动启用模型、不改变正在运行服务；连接与JSON协议成功仍不代表真实任务理解质量通过。没有真实密钥时应明确未验证，不能用模拟接口结果冒充真实API。

控制台只停止自己通过Popen创建、保留进程句柄且带独立实例标识的服务。先走私有标准输入管道正常退出，等待当前请求结束；超时仍显示停止中，可继续等待，或明确选择强制停止。没有网页停止接口，不按python.exe名称或历史PID批量结束。端口占用时不接管，可打开已核验的已有页面（普通标签页）或换端口。

打开页面优先使用Edge独立应用窗口和专用浏览器目录。只有窗口PID属于本控制台仍持有的活进程，且窗口标记一致，才允许发送WM_CLOSE。只关闭记录的项目窗口，不杀浏览器进程。手动关窗会被检测到，服务仍可运行。

如果Edge不可用，使用默认浏览器标签页；如果窗口归属不能核验，明确显示需手动关闭，“关闭项目页面”不会假装成功。打开已有服务的普通标签页也不归控制台管理。保留页面退出时，下次控制台可能无法核验旧窗口，需手动关旧页面。

退出时可返回控制台，或停止服务并退出；可选择同时关闭可核验项目页面。若停止超时，控制台保持打开，不谎称成功，也不无声留下后端孤儿。控制台意外退出会关闭私有管道，子服务正常退出并等待当前请求完成。

控制台底部可点击“创建桌面快捷方式”；同名快捷方式已存在时不覆盖。也可在资源管理器中右击启动控制台.vbs创建快捷方式。正式运行不需要Node、Playwright或VS Code。

教师页面会明确列出“服务器已保存的文件”和“本次新选择的本地文件”。刷新恢复时显示“已恢复历史任务”。“新建任务/从空白开始”只清除当前浏览器的活动指针，不删除旧上传、结果、草稿或审计；可从历史列表返回。尚未上传的本地文件不能跨刷新保留浏览器选择权限，草稿文本保留，恢复后需重新选择文件。

源码分发继续要求Git已提交且工作树一致。新增桌面入口、Tk控制台、受管子服务、窗口管理、配置模块及页面资源必须全部在白名单；secrets.local.json、实际配置、运行状态、日志、浏览器目录均不分发。未提交时如实拒绝，不绕过或自动提交。

专用Edge窗口使用独立浏览器配置。首次使用不会复制原默认浏览器的localStorage历史指针；原浏览器及原服务器数据仍保留。历史列表说明其来自本浏览器；跨浏览器指针迁移本轮未实现。

当前若8765已有旧服务，控制台会拒绝接管，可点击打开已有页面，或在控制台改为8767并使用独立状态目录。不要让两个服务同时写相同状态目录。

启动前会直接检查当前运行源码的语法；若提示程序文件及行号错误，无需更换密钥或重新上传数据。诊断区显示控制台实际使用的Python解释器，便于区分电脑上同时安装的多个Python。程序更新后重新打开控制台可加载新的启动检查，历史数据和已保存配置保留。
