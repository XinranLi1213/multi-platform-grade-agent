日期：2026-10-24。此版本是本机单用户、领域受限的最小 Agent 预览版，不代表任意模型、任意课程规则均已验证。

## 三项问题的处理

| 原问题 | 修改 | 最终验证 |
|---|---|---|
| 首次只显示文字问题 | 统一问题协议；兼容文字响应时由服务端自动请求真实模型选项，不再要求教师额外点击 | 两类完整上传任务各连续3轮首次显示模型选项，无默认选择 |
| 未知满分仍提出样本最大值 | 校验选项中的满分依据；新分制动作只接受百分制或教师填写明确满分；不把最大观测值当规则 | 未知满分任务询问后自定义50，输出40/0/80；真实模型生成填写满分选项，参数表单提交50也得到同样结果；无依据40分制被回归检查拒绝 |
| 自定义回答超时、方案非法 | 减少重复上下文、提供实际字段与权重键；格式修复带上一份错误响应；最多一次技术性重试；保持版本与执行门槛 | 自定义满分、各50%权重两条完整流程各3轮通过，输出分别40/0/80及50.0/90.0/10.0，实际下载逐值核对 |

扩展实测还发现summary_field引用不存在的列可能导致执行异常，现已在执行前检查。旧配置加载错误分类已修复。通用工作台保留原有字段建议逻辑，网络传输复用共享客户端的重定向阻止、截止时间与密钥脱敏。

技术性重试只用于理解请求或格式修复，不等于新增业务授权，也不会重复加分。外部API仍可能超时、限流或理解错误；失败时不把旧规则或结果作为本次成功，不要求重新上传。

## 其他电脑如何自行验证

先安装Python 3.11+，解压到普通可写目录。在项目根目录运行：

    python -B -X utf8 tools/verify_demo.py

它只使用公开基础案例，在系统临时目录启动独立随机端口的本机服务，不读取或修改已有任务，不调用模型API。成功后输出通过的检查；失败返回非零退出码。正常教师使用仍可双击控制台，无需命令行。

然后按examples/README.md依次上传各案例，在界面核对预期并下载结果。配置真实模型后再尝试05/06；连接检查不能替代任务验收。

维护套件位于独立support目录，包含完整历史回归与浏览器测试；不随正式运行源码加载，也不是下载仓库的运行依赖。维护环境实际命令包括dev.py test all、test_release_contracts.py、dev.py browser conversation、dev.py browser ui-options以及独立真实模型验收驱动。不要在缺少维护资料时声称这些套件已运行。

## 构建与完整性

tools/build_package.py仅从已提交的Git白名单生成运行ZIP，有相关未提交文件会拒绝，不自动提交或绕过。输出目录必须位于项目外：

    python -B -X utf8 tools/build_package.py --output 项目外目录/交汇.zip

包内RELEASE_MANIFEST.json记录源提交、版本和逐文件SHA256。不要手工替换历史路径、引擎哈希或原始输入来伪造迁移成功。GitHub源码ZIP也包含精选合成案例；正式程序不会自动加载它们。

## 限制与未运行

- 未在另一台物理电脑运行。本机独立中文、空格目录测试不能称作第二台电脑验证。
- 仅CSV，2–6份、每份不超过2 MiB；未测试大规模或任意自定义业务，不支持生产多人及公网部署。
- 真实模型验收只覆盖当前配置的服务和上述场景，不能推广为所有Chat Completions服务或所有自然语言任务。
- 外部API故障无法由本地程序保证消失。可恢复、不误执行、保留依据是异常路径的验收条件。
