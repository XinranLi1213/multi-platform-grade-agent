Agent能力与边界

程序固定编排“实际读取CSV→模型结构化方案→程序校验→必要问题→DWD工具→持久化→DWS工具→结果校验→保存/继续”。模型不能直接返回学生计算结果或人工确认。

已有工作流自动化：确定性清洗与计分、状态和版本、来源审计、人工问题卡片、规则继承、试算和恢复。
模型入口：非流式Chat Completions兼容服务；由实际数据统计和任务提出方案，结构及字段错误最多一次受控修正，保留校验反馈；传入后续执行状态的问题类别，不发送无授权的原始问题记录。
人工确认：身份归属、缺失依据、冲突值、排除和补值等必要裁决，模型不得冒充。

这是领域受限、程序控制工具选择的Agent框架。未配置或未验证真实模型时，实际能力是可恢复的工作流自动化，不能仅凭项目名或fixture验收声称真实模型闭环已成功。没有通用工具自主选择、无限自我修改或生产多人协调。
