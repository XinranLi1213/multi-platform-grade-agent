# 教师任务工作区

界面约定：以布局、分组和控件表达关系，文字只保留操作所需的信息。不重复解释左右区域、文件已保存或下一步按钮用途。补充说明按需展开；错误原因、待确认问题、当前版本、数据来源和执行反馈仍须准确可见。后续界面调整沿用此原则。

打开 `/pipeline`，左侧是任务对话，中间是任务指令、实际处理状态和已有整理/计分表单，右侧是当前任务文件。

任务输入位于工作区底部。上传后直接在原输入框补充，无需重新上传。只整理数据时计分区默认折叠；需要时再补充计算要求，见[自然语言任务与可选计分](intent_agent.md)。

- **新建任务**：从空白开始，保留旧任务及其上传、规则、结果、审计和未提交草稿。
- **左侧历史**：点击任务恢复对应文件与处理进度。可搜索任务文字和上传文件名。服务器任务保存在控制台所示状态目录；未上传草稿仅保存在本浏览器。
- **任务对话**：显示真正提交过的指令，以及根据流程状态生成的系统说明；不虚构模型回复。
- **右侧文件**：按原始上传、阶段一整理宽表、阶段二计算结果分组。点击弹出预览，显示任务版本、原始行或实际字段，并可下载完整文件。
- **仍有问题的整理宽表**：标为待确认，不能当作完成的清洗结果。没有有效计算结果时，不显示旧结果作为当前文件。
- **当前试算与已采用结果**：分别标识。同一整理版本下的已采用结果可单独查看，试算不会替换它。

输入文件预览保留原CSV中的说明行、真实表头和汇总行，以原始位置和原始列展示；不会把表头探测后的清洗结果冒充原始输入。显示最多100条记录，下载包含全部内容。空字符串显示为空缺，0与前导零保留。

预览与下载为只读操作，不能触发重算或替换输入。后台按流程版本检查，原始上传校验SHA256，宽表和计算结果继续使用现有持久化产物与哈希校验。修改阶段一后相关旧文件退出当前列表；仅改权重复用阶段一。

历史对话界面不提供删除原始数据的操作。关闭页面、停止服务均保留服务器任务。切换状态目录后，只能看到该目录对应的服务器任务；其他目录仍保留。不同浏览器不共享未上传草稿。

程序更新后刷新页面即可加载布局。若当前后端进程尚未重启，页面会明确注明使用本浏览器历史，并以已有保存数据和校验后的CSV提供兼容预览；原始文件下载暂不可用。完成当前操作后，在项目控制台停止再启动服务，即可启用服务器完整历史索引、按版本从文件读取的预览及原始文件下载，无需重新上传。


对话布局更新：输入区常驻中栏底部，待确认问题位于输入上方。主区域仅显示逐轮指令、实际反馈和数据入口；读取、整理、计算表通过查看器打开。中栏消息区内侧的纵向刻度可定位轮次，悬停或键盘聚焦可查看摘要；历史轮次的文件绑定当轮产物，不能作为当前执行输入。高级JSON编辑入口已移除，中文整理/计分表单仍在查看器中。技术诊断保留在本机控制台。

结构化问题支持可选处理方案和卡内自定义回答，默认不选择。选择后点击“提交此项”，其他未解决问题与草稿继续保留；“继续待确认”不会启动计算。旧文字问题仍可自定义回答；未启用模型时，自定义内容保存后需要用中文表单完成规则配置。

历史列表按真实处理时间分组排序，打开、预览或下载不会把任务置顶。条目显示时间；没有可靠创建时间的旧任务只标注最后保存时间。未上传草稿仍只保存在本浏览器。

教师下载入口默认提供中文TXT处理说明，包含完整记录、原值、来源位置、人工依据及版本，不受表格预览行数限制。CSV结果及内部JSON审计继续保留。旧轮缺少完整审计快照时会说明无法导出，不使用当前记录冒充历史说明。

待确认的具体选项可由真实模型根据问题、字段和实际统计提出，支持将“同一活动多次提交＋归并方式”组成一个方案，不强制拆成两次选择。选项以A、B、C排列，后附“自定义处理方案”；选中自定义才展开文字框。每项下的小字说明程序实际将采用的操作或尚缺条件，模型文字本身不绕过程序检查。

旧文字问题可在原任务卡片点击“根据问题生成选项”，保留上传、已有规则和当前问题；仅生成候选答案不会清洗或计算，也不会默认选中。生成失败仍可自定义回答。普通未配置模型的手动流程继续可用，旧固定类型仅兼容原任务，不冒充新的LLM选项。
